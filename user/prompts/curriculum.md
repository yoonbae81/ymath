# 분류 체계 (curriculum)

이 파일이 **영역(topic) · 단원 · 개념 ID의 유일한 원천**입니다. 오답 분석 결과와 보고서 분리의 기준이 됩니다.
코드 수정 없이 여기만 고치면 분석 선택지, `/results` 필터, 보고서 영역 선택이 함께 바뀝니다.
(예: 고3 과목이 필요해지면 `## 영역`, `### 단원 | 과정`, `- 개념ID | 설명`을 아래에 추가하면 됩니다.)

**작성 규칙 (파서가 읽는 형식)**

- `## 영역이름` — 영역(topic). 보고서는 영역별로 따로 만들어지며 영역이 섞이지 않습니다. 이 줄 형식의 제목은 모두 영역으로 취급되므로, 안내문에는 `##`를 쓰지 마세요.
- `### 단원이름 | 과정` — 단원. 단원 이름은 파일 전체에서 유일해야 합니다. 과정은 참고용 표기입니다.
- `- 개념ID | 설명` — 개념. ID는 `대문자-대문자-…` 형식이며 파일 전체에서 유일해야 합니다.
- 위 형식이 아닌 줄(이 안내문 포함)은 무시됩니다.
- 영역·단원·개념을 지우거나 이름을 바꾸면 이미 저장된 분석과 어긋날 수 있으니, 바꾼 뒤에는 해당 항목을 재분석하세요.

**학기 표시(`| 과정`)의 근거와 한계**

- 표기는 `학년-학기`이고, 고등학교는 `고1-1 공통수학1`처럼 과목 이름을 붙입니다. 이 값은 화면에 단원 옆에 보이는 **참고용**이며 분류에는 쓰이지 않습니다.
- 중2는 2022 개정 교재 목차, 중3은 2015 개정·2022 개정 교재가 같은 배열(3-1: 실수·인수분해·이차방정식·이차함수 / 3-2: 삼각비·원의 성질·통계)이라는 점과 실제 업로드 자료(쎈 중3-2의 삼각비)로 확인했습니다.
- 고1은 공통수학1 = 1학기, 공통수학2 = 2학기(교재 이름과 같음), 공통수학2는 도형의 방정식·집합과 명제·함수와 그래프입니다.
- **고2는 교육과정이 학기를 정하지 않습니다.** 대수 = 고2-1, 미적분Ⅰ = 고2-2, 확률과 통계 = 고2-2는 흔한 배열일 뿐이라 학교·교재에 따라 다를 수 있으니, 사용하는 교재에 맞게 고쳐 주세요.
- 영역 배정도 초안입니다(집합·명제는 대수, 도형의 방정식은 기하, 지수·로그·삼각함수는 함수, 수열은 대수, 극한·미분·적분은 미적분).
